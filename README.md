# DEMO-BD-DOCTOR-PORTFOLIO

Premium responsive doctor portfolio and WhatsApp appointment-booking demo for Bangladesh.

## Demo notice

All doctor details, credentials, statistics, testimonials, hospital/chamber names, schedule, contact details, and images are sample demonstration content. Replace with verified client information before any real deployment.

## Local preview

Serve this directory with any static HTTP server. The appointment form opens WhatsApp with a pre-filled request; it does not send messages automatically.

## Image sources

Images are loaded from Unsplash CDN URLs in `index.html` and should be replaced with licensed client assets before production use.
